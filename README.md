<summary>Instructions</summary>  

- Install Python: [Python Downloads](https://www.python.org/downloads/)
- Install requirements (run in the repository's root directory):
  ```bash
  pip install -r requirements.txt
  ```
- Install a sample dataset [example](https://www.kaggle.com/datasets/programmer3/industrial-fault-detection-dataset)
- Move the dataset to the data folder
- If not using the example dataset, change the 'DATA_FILE_PATH' to the file name of your dataset
